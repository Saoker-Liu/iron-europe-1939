# 钢铁欧陆 1939（Iron Europe 1939-1945）

一款仿照《欧陆战争》《将军的荣耀》《世界征服者》的**六边形回合制战棋策略游戏**，
以 **第二次世界大战欧洲战场（1939-1945）** 为背景。纯原生 HTML5 + Canvas + JavaScript，
零依赖、单机可玩。

![类型](https://img.shields.io/badge/%E7%B1%BB%E5%9E%8B-%E5%85%AD%E8%BE%B9%E5%BD%A2%E5%9B%9E%E5%90%88%E6%88%98%E6%A0%8E-gold) ![技术](https://img.shields.io/badge/%E6%8A%80%E6%9C%AF-%E5%8E%9F%E7%94%9FCanvas-blue)

## 如何运行

**方式一**：直接双击 `index.html` 用浏览器打开（无需服务器）。

**方式二**：本地服务器（推荐）

```bash
cd iron-europe-1939
python -m http.server 8631     # 或任意静态服务器
# 浏览器访问 http://127.0.0.1:8631
```

**运行测试**（Node.js ≥ 18）：

```bash
node test_logic.js   # 数据一致性校验 + 机制单测 + 3 阵营×80回合 AI 模拟
node debug_ai.js     # 观察 AI 互殴节奏的调试脚本
```

## 一、为什么选择二战欧洲战场

《欧陆战争》系列以拿破仑与两次世界大战最出名，《世界征服者》3/4 代的主舞台正是 1939-1945。
选择这个时代有三个理由：

1. **兵种体系完整**：步/炮/装/空四兵种克制关系清晰（步兵难啃坦克、坦克碾炮兵、炮兵隔山打牛、空军凌空一切），天然适配战棋的克制表设计；
2. **名将如云**：古德里安、隆美尔、曼施坦因、朱可夫、巴顿……每个人当时都有明确的"看家本领"，可以直接转译成游戏技能；
3. **战略剧本天然成立**：闪击战→西线僵持→巴巴罗萨→斯大林格勒→诺曼底，历史脉络本身就是一条难度曲线，玩家可以用决策复现或改写它。

## 二、游戏概览

| 项目 | 内容 |
|---|---|
| 地图 | **114×65 尖顶六边形真实欧洲**（1 格 ≈ 0.5°经度×0.5°纬度，由真实海岸线栅格化，见 build_map.js），含不列颠群岛、斯堪的纳维亚、伊比利亚、亚平宁靴子+西西里、波罗的海、黑海+克里米亚、地中海、安纳托利亚 |
| 海峡 | 多佛尔、博斯普鲁斯、墨西拿三处"浅滩"格，部队可徒步渡海（海狮/海峡登陆的抽象） |
| 地形 | 阿尔卑斯/比利牛斯/喀尔巴阡/高加索/托罗斯山脉，阿登与波希米亚森林，德国中部丘陵，俄罗斯森林带 |
| 阵营 | 轴心国 / 同盟国（英法美波）/ 苏联 + 18 个中立国（含波罗的海三国、低地国家、葡萄牙、爱尔兰） |
| 城市 | 77 座按真实经纬度放置（柏林 27,28 = 13.4E,52.5N），首都带 ★，**占领敌国首都 → 该国全境易手** |
| 中立 | 大国军队**开进中立国领土即触发倒戈**——德军踏入比利时，比利时即刻加入同盟国（还原 1940） |
| 回合 | 1 回合 = 1 个月，1939 年 9 月开战 |
| 兵种 | 步兵 / 炮兵(射程2，无反击) / 装甲 / 轰炸机(飞行，无视地形与ZOC) |
| 将领 | 16 位史实将领，独立技能 + 击杀晋升（5 星）系统 |
| 事件 | 10 个历史事件脚本：意大利参战、巴巴罗萨、美国参战、俄罗斯严冬、诺曼底登陆…… |
| 系统 | 金币经济、招募(装备随年份解锁)、驻防、老练度、控制区(ZOC)、AI、存档 |

**胜利**：击败所有交战敌对阵营的首都。**失败**：己方阵营首都全部陷落。

## 三、玩法手册（速览）

- **左键** 选择部队/城市；**蓝格** 移动；**红框敌军** 攻击（点击自动接敌）
- **拖拽** 平移地图，**滚轮** 缩放
- 快捷键：`N` 下一支待命部队 · `E/回车` 结束回合 · `G` 将领 · `H` 帮助 · `M` 静音 · `Esc/右键` 取消
- **驻防**（+30%防御，移动/攻击后解除）；部队在己方城市每月 +25 兵力，己方领土 +12
- 伤害公式 `42 × 攻/(攻+防)`，兵力越低输出越弱；近战会遭反击（炮兵/空军攻击不受反击）
- 兵种克制：坦克克炮(140%)、步兵怕坦克(65%)但克炮(130%)、空军全能但畏惧高射炮
- 中立国可以打，但它们会**倒向你的敌人**——历史上一锤子买卖都不做

### 三阵营玩法提示

- **轴心国**：前 21 个月是黄金窗口。但泽-华沙合围圈吃掉波军，然后**必须取道比利时**（踏入即倒戈）穿越阿登森林直插巴黎——历史上曼施坦因计划的游戏化；1941 年 6 月之前必须准备东线，否则巴巴罗萨的冬天会教做人。
- **同盟国**：开局守势。马奇诺（斯特拉斯堡山地）正面固守，佛兰德方向提防德军绕越低地国家；熬到 1941 年 12 月美国参战（伦敦出现美军装备+收入+40）、1944 年 6 月诺曼底登陆（10 个师在诺曼底海岸抢滩）就是翻盘时刻。
- **苏联**：1941 年 6 月前是和平备战期（约 21 回合攒钱爆兵）；开战后放弃边境、用空间换时间，冬天的俄罗斯会替你消灭侵略者（轴心国在苏境每月 -12 兵力）。

## 五、代码结构

```
iron-europe-1939/
├── index.html      页面骨架 + 全部样式（无框架）
├── data.js         静态数据：地形/114×65真实地图/77城/装备/16将领/事件/初始部署
├── build_map.js    地图生成器：按经纬度锚点栅格化真实海岸线 → MAP_ROWS
├── game.js         纯逻辑引擎（无DOM，可Node运行）：
│                   六边形数学(odd-r偏移↔立方坐标)、Dijkstra移动+ZOC、
│                   战斗结算(克制/地形/反击/士气衰减)、经济、AI、事件、胜负、JSON存档
├── ui.js           Canvas渲染(领土染色/雪景/动画)、鼠标键盘交互、面板/模态、
│                   WebAudio合成音效、AI回合回放、localStorage自动存档
├── test_logic.js   无头测试：数据校验/机制单测/80回合×3阵营模拟不变量
└── debug_ai.js     AI 行为观察脚本
```

核心设计决策：

1. **逻辑与表现完全分离**：`game.js` 不引用任何 DOM，`test_logic.js` 在 Node 里直接跑完整战役；
2. **六边形数学**：odd-r 偏移坐标 ↔ 立方坐标换算，距离 = 立方坐标分量差最大值；移动用 Dijkstra 而非 BFS（山地 3 费/平原 1 费），ZOC 用"进入敌邻格即终止"实现（古德里安/巴顿/空军豁免，还原装甲集群穿透）；
3. **伤害公式** `42×A/(A+D)`：出自《欧陆战争》同源的软杀伤曲线——攻击方收益递减，兵力衰减乘区 `0.55+0.45×HP%` 逼迫玩家轮换部队；
4. **首都崩溃机制**：占领一国首都 → 该国所有城市易手，模拟政府流亡/投降，让闪电战"斩首"成为可行且爽快的战略；
5. **AI 分层**：多源 Dijkstra 距离场做战略导航 → 残血回城/占空城/驻防的价值打分 → 期望伤害-反击代价的目标选择 → 按构成比例招募。

## 七、性能工程

114×65 大地图初版实测只有 **4 FPS**。用帧探针定位到根源：

| 测量项 | 数值 | 结论 |
|---|---|---|
| AI 逻辑 3 回合 | 172ms | 逻辑不是瓶颈 |
| 单帧渲染（同步） | 29.7ms | **渲染是瓶颈** |
| 地形 Path2D 构建（全图） | 332ms | 每帧重建几何是主凶 |
| 画布 fill/stroke 本身 | 0.3ms | GPU 光栅化不是问题 |

即：每帧对所有可见六边形重新做"字符串键查表 → Path2D 几何构建 → 多遍填充描边"，且城市名/单位兵种字的中文描边文本每帧重绘，可见格越多越卡（缩得越远越卡）。

**修复：离屏缓存分层渲染**

- **地形层**（地形色 + 网格描边 + 领土染色 + 浅滩波纹 + 城市建筑与名称）画进世界坐标的离屏画布，每帧只做 **1 次 drawImage** 搬运；
- 重建时机：城市易手/季节切换立即重建；缩放变化防抖 140ms 后重建；缓存分辨率上限 0.69（约 12M 像素，防爆显存）；
- **动态层**（单位/选中环/动画）保留逐帧绘制，但加视口剔除，且低倍速（格宽<11px）自动省略兵种字/星级等小文本；
- 移动范围高亮合并为单 Path2D；tooltip 同格跳过 DOM 重写；
- 领土归属查询由"每格 × 每城距离扫描"改为**多源 BFS 距离场**（O(格数)，Int16Array），易手后重建仅需几毫秒。

**修复后：同步单帧 0.65ms（约 45 倍提升），可满帧运行**；控制台可读 `window.__fps` 实时帧率。
