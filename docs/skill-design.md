# 将领技能维护

技能数据位于 `js/data/generals.js`，当前116位将领的技能、开局指派和设计依据见[将领名录](../GENERAL_CATALOG.md)。初始92位在地图上、24位待指派。不要维护另一份旧人物表或使用已经删除的分支指令。

## 一、引擎能力速查（设计前必读）

### 1.1 当前兵种与作战规则

陆军包括 `inf` 步兵、`art` 炮兵、`tank` 装甲；`air` 包括七类机场驻机。海军有独立舰种，目前不支持指派将领。炮兵射程由装备决定，可执行反击；飞机依照机场作战半径出击，可遭防空拦截，运输机不能攻击。不要用旧版“炮兵/飞机不会被反击”的规则设计技能。

### 1.2 已支持的 10 种技能效果

| 写法 | 效果 | 界面显示 |
|---|---|---|
| `{ k:'atk', m:0.25 }` | 攻击力 +25%（可加 `cls` 限定兵种） | `装甲·攻击力 +25%` |
| `{ k:'def', m:0.30 }` | 防御力 +30%（可加 `cls` 限定兵种） | `防御力 +30%` |
| `{ k:'mov', n:2 }` | 移动力 +2（可加 `cls` 限定兵种） | `装甲·移动力 +2` |
| `{ k:'nozoc' }` | 无视敌方控制区（ZOC） | `无视敌方控制区` |
| `{ k:'rng', n:1 }` | 炮兵射程 +1 | `炮兵射程 +1` |
| `{ k:'counter', m:0.30 }` | 反击系数 +30个百分点 | `反击系数 +30个百分点` |
| `{ k:'citydef', m:0.40 }` | 驻守城市时防御 +40% | `驻守城市防御 +40%` |
| `{ k:'vs', tgt:'art', m:0.40 }` | 对指定兵种伤害 +40% | `对炮兵伤害 +40%` |
| `{ k:'aura', m:0.10 }` | 相邻友军攻击按m增强（光环） | `相邻友军攻击按m增强（光环）` |
| `{ k:'rage' }` | 兵力低于 50% 时攻击 +15%（未配置m时的默认值） | `兵力低于50%时攻击 +15%` |

**设计参考**（具体值以当前数据为准）：
攻击/防御加成 10%–30%，对特定兵种克制 15%–40%，移动力 +1~+2，城市防御 40%–50%。
`rage` 的默认值为 +15%，`aura`/`atk` 等的 `m` 自己给值。

### 1.3 与当前引擎的兼容说明

- `aura` 读取 `m`（缺省0.10），包括机场驻机将领；对相邻一格同阵营部队生效，多个光环取最强，不影响自身或同格单位，载员不发出光环。
- `rage` 读取可选 `m`，缺省0.15，在兵力低于50%时生效。
- 空军 `mov` 增加作战半径和转场距离；空军 `rng` 不生效，陆上部队 `rng` 增加装备射程。
- `counter` 只增强满足当前反击条件的普通反击，不额外赋予反击能力；防空拦截单独结算。
- `vs air` 增强可合法攻击空军时的有效攻击，不会让步兵或坦克获得区域防空能力。蒙哥马利指挥防空炮时可加强对空拦截。
- `nozoc` 对空军冗余；城市防御只在防守城市时生效。


## 更新流程

保持已有将领ID稳定；更新数据后运行 `node build_general_catalog.js`、`node test_generals.js` 和 `node test_render.js`。`counter` 增加反击系数而不是最终伤害百分比；普通技能仅作用于其指挥单位，`aura`才是邻格光环。
