# 钢铁欧陆 1939 · 436城与基地地理重建版

原生HTML + Canvas + JavaScript六边形回合制战棋，可离线运行。

本仓库：[ttdnx2999-cmd/test_collab](https://github.com/ttdnx2999-cmd/test_collab)，主分支为 `main`。当前地图版本 `europe-1939-geographic-v8`。

## 在线部署

部署目标：[https://ttdnx2999-cmd.github.io/test_collab/](https://ttdnx2999-cmd.github.io/test_collab/)。地址仅在本仓库启用 GitHub Pages 且部署成功后可用，不指向原作者仓库的旧版本。

[查看最新检查与部署状态](https://github.com/ttdnx2999-cmd/test_collab/actions/workflows/deploy-pages.yml)。推送 `main` 后，工作流先检查脚本、地图和游戏运行，再打包静态站点并部署到 `github-pages` 环境；站点的 `version.json` 提供实际发布的提交、地图版本和城市数量。

首次启用需要仓库管理员在 [Settings → Pages](https://github.com/ttdnx2999-cmd/test_collab/settings/pages) 将 **Source** 设为 **GitHub Actions**。私有仓库需要支持私有仓库 Pages 的 GitHub 套餐。未启用时，代码更新和测试仍可完成，但 Deployment 不会成功；管理员启用后可在 Actions 中重新运行部署工作流。

## 打开游戏

直接用浏览器打开本目录的 **index.html**，不需要网络、安装依赖或访问公开试玩站。

- 开始界面的“浏览1939地图”：直接查看政区全图。
- “地图全览”：恢复整个战区视图。
- “查找城市”：按城市、国家或地区搜索，点击结果放大定位；搜索“诺曼底”可找到卡昂、瑟堡等5座城市。
- “政区 / 地形”：切换国家色与自然地形。
- “隐藏部队 / 显示部队”：检查地图时隐藏棋子。
- 拖动平移、滚轮缩放；悬停查看1939归属与经纬度。

地图采用1939年8月31日开战前夕国界；战役仍从1939年9月开始，以一个月为一回合。详见 [地图依据及限制](MAP_NOTES.md)。

## 地图

128×112格，格心约45公里，兰伯特等角圆锥投影；436处城市、港口与基地。海岸、天然湖泊与河流基于Natural Earth，1938历史边界经1939事件校订。国家边界、阵营和军事控制权分开处理。

包含独立的斯洛伐克、卢森堡、但泽自由市、德国控制的波希米亚和摩拉维亚保护国、意占阿尔巴尼亚。保留战前波兰、芬兰和罗马尼亚领土；土耳其首都为安卡拉。克里米亚经彼列科普连接大陆；英国及主要岛屿没有虚构陆桥。

本轮新增107处地点，总数由329增至436。补齐苏黎世、日内瓦、巴塞尔、鲁汶、那慕尔、海牙、乌德勒支、布雷达、欧登塞、奥尔堡，以及指定的瑞典、芬兰和土耳其城市；同时增加北欧内陆、波兰东部、苏联西部、巴尔干及西欧的地区中心。瑞士共8处、荷兰9处、瑞典17处、芬兰13处、土耳其18处、苏联74处。各国总收入预算不变，见[新增城市与地区覆盖名录](CITY_CATALOG.md)。

密集地区改为统筹分配本国城市格位，避免较早加入的城市把其它城市推远；日内瓦和荷兰南林堡保留狭窄领土的格网表达，海牙保持在乌德勒支以西。436处节点均使用独立可占领格位，位置偏移最大约41公里。欧登塞位于菲英岛；岛屿与大陆之间须购买运输舰艇，经海面航行，不添加陆桥。

基尔运河沿布伦斯比特尔—伦茨堡—基尔霍尔特瑙的地理走向绘制为青色水道，局部放大时显示名称，必要时以引线避让，并说明1939年使用的“威廉皇帝运河”名称。它是窄运河标识，保留桥梁／渡口的陆路通行抽象；没有把德国切成海岛，当前不提供舰艇穿越运河的额外通道。“萨列马岛”在地区层显示、库雷萨雷在城市层显示，归1939年爱沙尼亚，可由运输舰艇航行至爱沙尼亚本土。搜索“基尔运河”或“萨列马岛”可定位相关港口。

保留阜姆、帕尔马、斯卡帕湾、法罗、泽西和扬马延等上一轮补充，以及柯尼斯堡旁苏联飞地的修正。马恩岛及泽西是英国王室属地，游戏归入英国；奥兰属于芬兰，显示非军事区身份并禁止本地招募；扬马延表示气象站／登陆补给点，而非正规港口。

## 地名随缩放分级显示

海域、岛屿与地区名称独立于国家归属；加入比斯开湾、科西嘉岛、撒丁岛、西西里岛、马耳他岛、塞浦路斯、十二群岛、爱琴群岛，以及苏格兰、威尔士、北爱尔兰、白俄罗斯、乌克兰、卡累利阿、克里木半岛、北高加索、亚美尼亚、格鲁吉亚、阿塞拜疆、比萨拉比亚等。岛屿文字以真实经纬度为锚点，必要时使用引线避让。

| 缩放层级 | 展示的文字 |
|---|---|
| 全览 | 国家、主要地区与大海域；例如苏联、乌克兰、白俄罗斯、北高加索 |
| 适当放大 | 次级地区、岛屿、海湾和主要城市；例如克里木半岛、库班、格鲁吉亚、巴库、塞瓦斯托波尔、罗斯托夫 |
| 继续放大 | 局部地区、海峡和主要＋次级城市；例如阿布哈兹、阿扎尔、刻赤半岛、巴统、索契、刻赤 |
| 距最大倍率约4～5次滚轮 | 当前视野内全部城市的名称，并持续保留至最大倍率 |

只有地区等地理文字随层级替换；城市名逐级累加，主要城市出现后持续显示，再加入次级城市，最后加入所有城市。城市符号、悬停详情和搜索仍可使用；搜索定位会放大至全部城市层，确保目标名称可见。右下角图例显示当前层级。文字按屏幕像素绘制，优先为城市名安排位置，再避让地区文字；已达到显示级别的城市名不会因切换层级或避让而省略。

补充的地理单元按尺度分层：

- **全览层**：斯堪的纳维亚、安纳托利亚半岛、伊比利亚半岛、亚平宁半岛、巴尔干半岛、西欧平原、中欧平原、东欧平原、乌拉尔山脉、波罗的海三国。
- **地区层**：奥克西塔尼亚、加利西亚（西班牙）、加利西亚（东欧）、比利牛斯山脉、阿尔卑斯山脉、奥地利、克罗地亚、莱茵兰。
- **局部层**：波西米亚、摩拉维亚、斯洛文尼亚、多布罗加、鲁尔区。

“加利西亚”的西班牙与东欧同名地区分开标注；“奥克西塔尼亚”表示历史文化地区，不套用现代法国行政大区边界。地区名不会改变1939年的国家归属。

## 游戏规则

三阵营：轴心国、同盟国、苏联。步兵/装甲/炮兵/空军，城市收入与招募，将领加成、控制区、驻防、老练度、历史事件和存档。

- 左键选部队/城市，蓝格移动，红框目标攻击。
- `N` 下一部队，`E/回车` 结束回合，`G` 将领，`H` 帮助，`M` 静音。
- 己方城市每回合恢复25兵力，己方领土恢复12。
- 攻占首都仍触发原版全国城市易手规则；它是战棋抽象。
- 跨主要河流额外消耗1移动力；海洋、湖泊不可供陆军通过。
- 固定海运航线已删除：陆军配备运输舰艇后逐格航行，下海和上岸分别耗尽当回合移动及攻击。
- 空军可飞越海洋与湖泊，但不能停在水面。
- 进入中立领土可触发倒戈；意大利及其阿尔巴尼亚占领区1940年6月参战。

地图版本为v8，旧地图存档不兼容；新版使用独立存档槽，不覆盖或删除旧存档。刷新本地index.html后选择“浏览1939地图”或开始新战役。搜索“马恩岛”“哥特兰”“奥兰”“威尔士”“巴奇卡”“西巴纳特”“高加索”或城市名称即可定位。

## 海上运输与登陆

选中沿海且本回合尚未移动／攻击的陆军，在部队面板购买运输装备，再点击相邻空海格下海。无需限定港口或固定航线；海上棋子显示“船”。科技随年份自动解锁，各阵营采用同一首版数值。

| 装备 | 解锁 | 购买价格 | 海上移动力 | 海上防御 | 海上攻击保留 |
|---|---:|---:|---:|---:|---:|
| 运输船 | 1939 | 25金 | 5 | 6 | 20% |
| 两栖运输舰 | 1942 | 55金 | 5 | 12 | 45% |
| 两栖突击舰 | 1944 | 90金 | 5 | 18 | 70% |

- 舰艇绑定部队、上岸后保留，可再次使用；沿海升级只补差价，不允许海上换舰或降级退款。
- 下海、上岸都是独立的一格转换，当回合立即结束移动及攻击。不能从内陆一路冲进海洋，也不能航行后在同回合上岸。
- 航行只经过海洋格，不经过湖泊或陆地；移动力固定，不继承坦克或将领的移动加成。正常航行后仍可攻击。
- 海上所有陆军射程统一为1；炮兵也不能在运输状态使用远程炮击。攻击保留比例作用于攻击属性，不直接等于最终伤害比例。
- 可攻击相邻守岸敌军，并承受反击；击败守军后，仍需下一回合向空海岸登陆。上岸恢复原兵种属性，可占领空城市。
- 海上防御采用舰艇数值，不叠加原装甲、驻防或陆军将领防御。不能海上驻防或自动补员；舰艇与所载部队共用兵力，沉没即损失该部队。
- 空军不购买舰艇，仍可越过水面、在陆地停留。AI也会购买运输舰艇、下海航行及登陆。

两栖突击舰表示二战登陆运输与突击艇编队的游戏抽象，不是现代直升机两栖舰。年份与参数用于首版玩法，不代表所有国家同年拥有同等装备；现已接入独立海军；隐蔽探测、独立舰载机和区域制海权尚未实现。

此机制兼容旧v8陆上存档，旧部队默认为未配备运输舰艇；新存档记录装备和登船状态。完整规则与回归结果见[交付校验](artifacts/VALIDATION.md)。

## 军港与独立海军

39处军港位于所属城市的相邻海格，包括指定的斯卡帕湾、普利茅斯、朴次茅斯、汉堡、威廉港、基尔、布雷斯特、马赛、土伦、热那亚、威尼斯、塔兰托、塞瓦斯托波尔、敖德萨、列宁格勒。点击海格上的 **⚓** 或城市面板的“打开军港”，即可花费经济建造当前年份最先进的舰型；每舰种最多保留三型发展路线。泊位需空闲，新舰下回合行动。

支持潜艇、驱逐舰、轻巡、重巡、战巡／大型巡洋舰、战列舰、护航／轻型航母、航母八类。德国、英国、法国、意大利、苏联、美国使用史实或计划舰型；日本八类舰型作为资料预留，无欧洲造船入口。其余国家使用基础／改进／先进三型。美国参战后英国盟军军港可建美舰。计划舰、史实分类差异和游戏年份均在界面与[完整舰型表](NAVAL_CATALOG.md)注明。

军舰仅航行于海面；具有反潜克制、射程内反击、岸轰及航母远程打击，不能占领陆地城市。己方军港每回合修复25兵力。军港控制权随所属城市改变，已建舰艇保留原阵营。AI会造舰、出航、攻击与返回军港维修。

汉堡易北河口和列宁格勒芬兰湾东端补上水面入口，城市位置和初始部署未改变。直布罗陀、达达尼尔、博斯普鲁斯海峡以短距离水道连接保持通航，消耗实际格距的移动力；不是旧海运航线。基尔运河仍只有地理标记。存档结构升为v5，继续读取v3/v4；旧陆军若正处在新增河口海格，会保留原位并配备基础运输船；原地空军迁至相邻空闲陆格。

新增检查：`node test_naval.js`，覆盖港口邻接与外海连通、八类舰型、德国解锁、建造权限与费用、泊位占用、海军移动／攻击／维修、城市易手、存档和AI。
